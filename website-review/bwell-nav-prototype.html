Behavior checklist (ตรวจรับ)

#พฤติกรรมเกณฑ์ผ่าน
1Hover เปิด flyoutเปิดหลังชี้ค้าง 120ms สลับหมวดโดยไม่ปิด-เปิดใหม่ ปิดเมื่อเมาส์ออกจาก bar+flyout เกิน 200ms
2Click / Tapคลิกชื่อหมวดครั้งแรก = เปิด flyout (ไม่ไปหน้า) คลิกซ้ำ = ไปหน้า category
3KeyboardTab ไล่ทุก item, Enter/Space เปิด, Esc ปิดและคืน focus, focus ออกนอก flyout = ปิด
4Curtainคลิกพื้นที่มืดปิด flyout; เนื้อหาใต้ curtain ไม่รับ click
5Searchเปิดแล้ว focus ที่ input ทันที; Esc ปิด; ลิงก์ด่วนแก้ได้จาก WP menu
6Mobileเปิดเมนูแล้ว body ไม่ scroll; submenu slide 360ms; ปุ่มย้อนกลับ; ปิดด้วย X
7StickyBar ติดบนเสมอ ไม่กระโดดตอน scroll; safe-area บน iPhone
8Performanceไม่โหลด JS เพิ่มเกิน 6KB; ไม่มี layout shift ตอนเปิด (ใช้ fixed flyout)
9TrackingGTM event nav_click พร้อม data-nav="air/สำรวจ/เครื่องฟอกอากาศ" ทุกลิงก์
