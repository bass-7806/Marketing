      Spec: Bwell Compare Page · หุ่นยนต์ดูดฝุ่น (apple.com/th compare pattern)

      หน้านี้ใช้ pattern หน้าเปรียบเทียบของ Apple ได้แก่ เลือกรุ่นด้วย dropdown สูงสุด 3 คอลัมน์ (มือถือ 2 คอลัมน์) แถบเลือกรุ่นติดบนจอขณะเลื่อน หัวคอลัมน์มีภาพ ราคา และปุ่มซื้อ จากนั้นเป็นแถวสเปกแยกตามหัวข้อ ค่าทุกช่องมาจากหน้าสินค้าจริงบน bwell.co.th ณ 29 ก.ย. 2026 ช่องที่หน้าสินค้าไม่ได้ระบุแสดงเป็น —

      พฤติกรรม

      ส่วนการทำงาน
      Dropdownเลือกรุ่นที่แสดงอยู่แล้วในอีกคอลัมน์ = สลับตำแหน่งสองคอลัมน์ ไม่เกิดรุ่นซ้ำ
      URLรุ่นที่เลือกเก็บใน ?models=t20,l6c,l0 ส่งลิงก์ต่อได้ และหน้าสินค้า/หน้าหมวดลิงก์มาพร้อมรุ่นที่เลือกได้
      Sticky barติดใต้ global nav ขณะเลื่อน มีเส้นขอบเมื่อติด
      มือถือแสดง 2 คอลัมน์ ซ่อน dropdown ที่ 3
      Trackingdata-nav="compare/..." → GTM compare_click และควรส่ง compare_models ทุกครั้งที่เปลี่ยน dropdown
      Flatsomeใช้ JSON สเปกจาก WooCommerce attributes ต่อรุ่น แล้ว render ด้วยสคริปต์เดียวกับ prototype ไม่ต้องทำตารางแยกต่อหมวด
