Recommendation

ลด spend ที่หลุดไป Bewell และ query ที่ไม่ใช่ลูกค้าก่อน แล้วย้ายเงินไปที่ brand, model และ health need-state

Paid search ของ Bwell ใช้เงินไปกับคำกว้างๆ (generic) และคนที่ตั้งใจหาแบรนด์อื่นเกินครึ่ง ส่วน transactions ที่ track ได้แทบทั้งหมดมาจากคนที่ค้นชื่อ Bwell อยู่แล้ว เงินที่ประหยัดได้ควรย้ายไปที่ keyword ซึ่งตรงกับ positioning ด้าน health และ safety (PM2.5, ภูมิแพ้, RO, ไรฝุ่น) แทนที่จะลงไปแข่งราคากับแบรนด์จีน

Action plan · 30 วัน

5 อย่างที่ต้องทำ เรียงตาม impact ต่อต้นทุน

  1. ใส่ account-level negative list วันนี้bewell, บีเวล, ชื่อสินค้า Bewell (frozen, glory, enlight, topper, ที่นอน), มือสอง, เช่า, ราคาถูก, ช่วยอะไร, วิธี รวมแล้วตัดได้กว่า 2,000 paid sessions ต่อ 90 วัน ซึ่งมี 0 transactions ทั้งหมด
  2. แยก campaign Brand ออกมา (Bwell + category + model + filter)ใช้ Exact/Phrase เพิ่ม exact keyword สำหรับชื่อรุ่น (CF-8608, AP-M1536S, BDH-30A, BPAC-12B ฯลฯ) ซึ่งตอนนี้ยังไม่มี keyword ของตัวเอง แล้วได้ traffic ผ่าน generic match
  3. ปรับ generic ad groups เป็น Phrase และแยก ad group ตาม need-statePM2.5 / ภูมิแพ้ / ห้องนอน / ตากผ้า / RO / ไรฝุ่น / ปวดหลัง เขียน ad copy เรื่อง health benefit ไม่ใช้ราคาเป็นจุดขาย ลด bid ที่ robot vacuum และ hair generic
  4. แก้ Merchant feedbrand ว่าง 291 จาก 300 SKU, product_type ว่าง, title มี suffix "| Bwell จำหน่าย..." และมี listing ซ้ำ ให้เริ่มที่ SKU ที่ impressions สูงแต่ CTR ต่ำก่อน (AP-M1536S, BW-D10RO5, 201A, ELKA)
  5. ติด conversion ที่จับยอดขายนอกเว็บได้Click-to-Shopee/Lazada, LINE add friend, โทร และ store visit ก่อนจะเปิด Broad match หรือ Smart Bidding เพิ่ม เพราะเว็บทั้งเว็บมีแค่ 42 transactions ใน 90 วัน

Finding 2 · Brand confusion

Bwell ซื้อ traffic ให้ Bewell อยู่

Keyword "bewell" ยังได้ traffic

ใน 90 วันที่ผ่านมา keyword นี้ได้ 1,229 sessions และ 0 transactions โดย query เป็น bewell, bewell สาขา, เก้าอี้ bewell, หมอน bewell, bewell เชียงใหม่ คนกลุ่มนี้ตั้งใจหาร้าน Bewell

"ergonomic chair" ก็โดน

41% ของ traffic ที่ keyword "ergonomic chair" (358 จาก 877 sessions) เป็น query ที่มีคำว่า bewell อยู่ด้วย และใน site search ของเว็บ Bwell เองก็มีคนพิมพ์ชื่อสินค้า Bewell เช่น Frozen, Glory, Enlight, Foster, T-10

คำแนะนำ: pause keyword "bewell" ใส่ negative ระดับ account (รวม PMax brand exclusion) และอย่าใช้ "เก้าอี้เพื่อสุขภาพ" เป็นคำหลักของ ergonomic ให้ไปเน้น pain-point แทน (ปวดหลัง, ออฟฟิศซินโดรม, เบาะรองนั่ง)

Decisions & data gaps

สิ่งที่ต้องตัดสินใจ และ data ที่ยังขาด

ต้องตัดสินใจ

  • Competitor brands (Xiaomi, Dyson, Philips, Coway ฯลฯ) จะ negate ทั้งหมด หรือแยก conquest campaign และตั้ง budget cap
  • Water heater ยังเป็น focus category อยู่หรือไม่
  • Hair styling จะลด Google Search แล้วไปเน้น Marketplace หรือไม่

Data ที่ยังขาด

  • Google Ads cost / CPC: ยังคำนวณ CPA / ROAS ราย keyword ไม่ได้
  • Search volume ตลาด: Semrush API units หมด และ Ahrefs plan ไม่รองรับ
  • Search Console, Shopee, Lazada และ TikTok Shop keyword report
