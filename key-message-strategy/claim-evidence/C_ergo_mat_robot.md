- **Product Master:** `Product_Facts` tab. It has rows for Move, T20 and Greta Black identity only. It has no rows for BIFMA, chair base material, cushion materials or T20 edge cleaning.
- **Drive:** searches for BIFMA, X5.1, ANSI/BIFMA, BIFMA with report/SGS/Intertek/TÜV, ลิขสิทธิ์แท้, illuztika, เครื่องหมายการค้า, license agreement, chair model titles, and T20 with corner/edge/ชิดขอบ/มุมห้อง. - **Unrelated "Bwell" brands:** "Bewell", a separate Thai brand, sells similar chairs, cushions and TPE yoga mats. "Foshan Bwell furniture" (th.bwellsit.com) is also a different company. Neither is evidence for these claims. No source states that "ลิขสิทธิ์แท้" refers to them.

## Other observation

The chair pages' meta description (og:description) shows wrong text. For example, the Stella page's description reads "bwell-เก้าอี้เพื่อสุขภาพ รุ่น Greta". The internal matrix records a similar CMS bug, which it describes as short descriptions showing air-purifier text.
