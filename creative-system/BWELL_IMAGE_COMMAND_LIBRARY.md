## PART A — CUSTOM INSTRUCTION (วางใน ChatGPT / Gemini / Grok / Claude Project ทุกตัว)

```text
When I include slash commands in a Bwell image request, treat them as technical visual modifiers
defined in BWELL_IMAGE_COMMAND_LIBRARY.md. Interpret them by standard photography, art direction
and cinematography conventions, without conversational commentary.

Bwell locks override every command:
1. Commands apply to the SCENE (background, light, camera, props, composition) — never to the product.
   Every scene prompt ends with: no product, no appliance, no brand, no text, no logos, no watermark.
2. The product is placed afterwards from the official packshot via /bwell-composite7.
   Any AI redraw or angle change of the product must be reported to Bass (SKU, source file, what changed).
3. The Bwell logo is never sent to or generated by an image model; it is overlaid from the official file.
4. Commands that change product color, material, design, logo or internal mechanism are BLOCKED (Part F).
5. Colors, fonts, logo size and safe areas follow BWELL_CI_QUICK_SPEC.md.
If a command conflicts with these locks, output CONFLICT DETECTED and ask Bass.
```
