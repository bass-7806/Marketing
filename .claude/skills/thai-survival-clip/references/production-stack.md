# เครื่องมือ การติดตั้ง และเสียง

## สิ่งที่ต้องมีในเครื่อง
| อย่าง | ใช้ทำ | ตรวจด้วย |
|---|---|---|
| ffmpeg / ffprobe | ตัดต่อเสียง วัดความยาว | `ffmpeg -version` |
| Node.js + npx | รันไฮเปอร์เฟรมส์ (`npx hyperframes`) | `npx hyperframes --version` |
| Python 3 | สคริปต์ของสกิล | `python3 --version` |
| uv | รันมิวสิกเจนโดยไม่ต้องติดตั้งไลบรารีเอง | `uv --version` |
| สกิลไฮเปอร์เฟรมส์ | กติกาการเขียนคลิป | `npx hyperframes skills update` |
| ฟอนต์ไทย | ซับและการ์ด | ดูหัวข้อฟอนต์ |
| คีย์อีเลฟเว่นแลบส์ | เสียงพากย์ | ดูหัวข้อเสียงพากย์ |

## ฟอนต์
- บนแมค ใช้ "Sukhumvit Set" ที่มากับเครื่อง (`@font-face local()` ใน `framework.py`) ไม่ต้องดาวน์โหลด
- เครื่องที่ไม่ใช่แมค ไม่มีฟอนต์นี้ → ดาวน์โหลดฟอนต์ไทยฟรี (เช่น Noto Sans Thai หรือ Kanit จาก Google Fonts) ใส่ `video/assets/fonts/` แล้วแก้ `FONT` ใน `framework.py` เป็น `src:url("assets/fonts/ชื่อไฟล์.ttf")` — ขออนุญาตผู้ใช้ก่อนดาวน์โหลด

## ดนตรีประกอบ (มิวสิกเจน ในเครื่อง ฟรี)
- `scripts/musicgen_bed.py "<คำอธิบาย>" <วินาที> <ไฟล์.wav>` — สร้าง 27 วินาทีแล้วต่อวนให้ครบความยาว
- ครั้งแรกดาวน์โหลดโมเดล ~2.3 GB + ไลบรารี ~300 MB (ผ่าน `uv run --with ...` ดูคำสั่งเต็มใน SKILL.md)
- **เครื่องแรม 8 GB**: รันตอนไม่มีเรนเดอร์หรือพรีวิวอื่นทำงาน; สคริปต์ใช้ float16 บน MPS แล้ว (fp32 ค้างเพราะสลับหน่วยความจำ)
- คำอธิบายที่ใช้ได้ดีกับแนวนี้: `dark suspense ambient underscore for a horror documentary, low sustained cello drone, slow heartbeat pulse, sparse eerie piano notes, tense and mysterious, 70 bpm, no drums, no vocals`
- วางในคลิประดับ 0.14 ใต้เสียงพากย์ ลดเหลือ 0.03 ช่วง "ทุกอย่างถูกหมด…" แล้วกลับขึ้นตอนหักมุม ตัดเงียบตอนจอดำ (ดู `data-automation` ใน `examples/flood-ep1/audio_cues.json`)
- คุณภาพดนตรีต้องให้คนฟังตัดสิน — ผู้ช่วยวัดได้แค่ความดัง

| `impact-bass-1.wav` | กระแทกทุ้ม ตอนจอดำ | คลังไฮเปอร์เฟรมส์ |

ต้องการเสียงอื่น: `scripts/openverse_sfx.py "<คำค้นอังกฤษ>"` แสดงรายการ (เฉพาะ CC0/CC BY) แล้ว `--get N --out ไฟล์` เพื่อดาวน์โหลด — เซิร์ฟเวอร์ช้า (20+ วินาที) และจำกัดจำนวนครั้ง ให้เว้น ~10 วินาทีระหว่างคำค้น; เสียง CC BY ต้องให้เครดิตในแคปชันคลิป
- จังหวะ: วางให้จุดดังของเสียงตกหลังภาพ 1 เฟรม — `npx hyperframes audio <ไฟล์> --json` บอกค่า onset แล้วตั้ง start = เวลาภาพ + 0.033 − onset
- เสียงที่ซ้อนเวลากันต้องอยู่คนละแทร็ก (`"track"` ใน audio_cues.json)
- ทุกเสียงต้องมีเหตุบนจอ อย่าใส่เพราะ "ให้มีเสียง"

## เรนเดอร์และความดัง
- `npx hyperframes render -o <ไฟล์.mp4> --workers 2` (68 วินาที ≈ 5 นาทีบนแมคแรม 8 GB)
- แล้ว `scripts/finalize.sh <ไฟล์ที่เรนเดอร์> <ไฟล์สุดท้าย>` ยกความดังเป็น −15 LUFS (มาตรฐานติ๊กต็อก) โดยไม่เข้ารหัสภาพใหม่
