# คู่มือภาพ และคลังชิ้นส่วนฉาก

## หน้าตาโดยรวม
- ภาพเวกเตอร์แบนแบบการ์ตูนอธิบาย วาดด้วยเอสวีจีในโค้ด ไม่มีเส้นขอบ เงาเป็นก้อนสีทึบ
- ฉากเต็มเฟรมเสมอ (ห้ามพื้นดำว่างมีของลอยกลางจอ)
- สีกดลงแบบหม่น + ฟิล์มเกรน 16% + ขอบมืด 55% (ใส่ให้อัตโนมัติจาก `framework.py`)
- สีแดง `#c9353a` ใช้เฉพาะของอันตราย: กล่องซับวลีสำคัญ แถบระดับอันตราย เส้นท่อ/ลูกศรอันตราย
- ตัวละครหัวกลม ตัวผอมสูง หน้าเรียบ (ตา 2 จุด) ใส่ชุดไทยจริง
- ฉากไทยแท้: ธงชาติ, กระดาน "ม.4/2", เถียงนา, ร่มชายหาด, ตู้ไฟ, สายด่วน ปภ.

ชุดสีอยู่ใน `scripts/lib_draw.py` ตัวแปร `C` — เปลี่ยนที่เดียวทั้งซีรีส์

## พื้นที่บนจอ 1080×1920 (ติ๊กต็อกบังขอบ)
| แถบ | ใช้ทำอะไร |
|---|---|
| 0–168 พิกเซล | ห้ามมีตัวอักษร (แถบสถานะ/ค้นหา) |
| 200–560 | การ์ดข้อมูล (`.card` top 230) และนาฬิกามุมจอ (`.chip`) |
| 560–1130 | ตัวเอกของช็อต |
| 1130–1300 | ซับ (ตายตัวที่ top 1130) — **อย่าวางสิ่งที่ต้องเห็นตรงนี้** เช่น ผิวน้ำในชักโครก |
| ใต้ 1330 | แค่พื้นผิว/ฉากหลัง ห้ามตัวอักษร (แคปชัน ปุ่มไลก์) |
| ขวา ~120 พิกเซล | ห้ามตัวอักษร (แถบปุ่มด้านขวา) |

## การเคลื่อนไหว
- ทุกช็อตกล้องซูมเข้าช้า 100% → 104–116% (`push=` ใน `scene()`) แบบ sine.inOut
- หนึ่งช็อต หนึ่งการเคลื่อนไหวหลัก (หูหมุน, คันโยกสับลง, เงาผ่านใต้น้ำ) ที่เหลือนิ่ง
- การ์ดเข้า: เลื่อนขึ้น 40 พิกเซล + จางเข้า 0.4 วิ ตัวเลขนับขึ้น 0.6 วิ (`js_card`)
- ผิวน้ำ/ฝน: เลื่อนวนแบบไม่จำกัดด้วย `js_scroll` (ทำซ้ำจำนวนรอบจำกัด ไม่ใช้ repeat:-1)
- วงกระเพื่อม: `ripple()` + `js_ripples()`
- ตัดตรง ไม่ใช้ทรานสิชันหวือหวา ก่อนหักมุมใช้ช็อตมืด/เทียนเล่มเดียว ตอนจบตัดดำทันที
- ช็อตละ 3–7 วินาที (ช้ากว่าคลิปแนวตั้งทั่วไป แต่ตรงกับจังหวะเล่าเรื่องสยองแบบนี้)

## คลังชิ้นส่วน (`scripts/lib_draw.py`)
ทุกฟังก์ชันคืนสตริงเอสวีจี วางบนผืน 1080×1920

| ฟังก์ชัน | วาดอะไร | หมายเหตุ |
|---|---|---|
| `sky(h, moon, stars)` | ท้องฟ้ากลางคืน ดวงจันทร์ ดาว | |
| `treeline(y)` | แนวต้นไม้/ต้นตาลเงาดำ | |
| `water(y, h, wid, lines)` | น้ำท่วม + ลายคลื่น (กลุ่ม id=wid ให้เลื่อนได้) | |
| `rain(wid)` | ฝน (สองชุดซ้อนให้เลื่อนลงต่อเนื่อง) | `js_scroll(dy=1920)` |
| `house(x, base, w, h, ..., lit)` | บ้านแถวสองชั้น หน้าต่างติดไฟได้ | |
| `cat(x, y, s, face, tail_id, ear_id, eye_id, puff)` | แมวส้มนั่ง หันขวา/ซ้าย/หลัง | หาง/หู/ตาขยับได้ผ่าน id |
| `person_sitting(x, y, s, face)` | คนนั่งกอดเข่า | |
| `door(x, y, w, h, gap_id, sign)` | ประตูห้องน้ำแง้ม ป้ายห้องน้ำ | ช่องมืดขยายได้ |
| `toilet_front(x, y, s)` | ชักโครก (น้ำ id=toilet-water) | ผิวน้ำอยู่ที่ y − 232×s |
| `ripple(cx, cy, rx, ry, rid)` | วงกระเพื่อม | |
| `croc(x, y, s, cid)` | จระเข้ใต้น้ำ เห็นแค่ตาและจมูก | |
| `flashlight_floor(x, y, angle)` | ไฟฉายวางพื้น + ลำแสง | |
| `candle(x, y, fid)` | เทียน + แสงอุ่น (เปลวไฟขยับได้) | |

ช็อตไหนต้องการของใหม่ (ตู้เย็น, เรือ, งู, รถ) → **เพิ่มเป็นฟังก์ชันใหม่ใน `lib_draw.py`** ด้วยรูปแบบเดียวกัน แล้วบันทึกลงตารางนี้ คลังจะโตขึ้นทุกตอน ตอนหลังๆ จะเร็วขึ้นเรื่อยๆ

## ชิ้นส่วนบนจอ (HTML ใน `overlay=`)
- การ์ดข้อมูล: `<div class="card" id="sXX-card"><div class="t">หัว</div><div class="n" id="sXX-n">15<small>ซม.</small></div><div class="t">คำอธิบาย</div>{danger_bar(4)}</div>` + `js_card("#sXX-card", เวลา, "#sXX-n", 15)`
- นาฬิกามุมจอ: `<div class="chip" id="sXX-clock">🕗 20:00 น.</div>`
- หน้าจอมือถือ: ดูช็อต s10 ใน `examples/flood-ep1/shots.py`
- การ์ด "ตอนต่อไป": ดูช็อต s15

## ข้อผิดพลาดที่เคยเจอ (อย่าทำซ้ำ)
1. **จุดหมุนของชิ้นส่วนเอสวีจี**: ห้ามใส่ `style="transform-origin:..px"` ให้กำหนดใน GSAP เสมอ เช่น `transformOrigin:"100% 100%"` (หาง), `"50% 100%"` (หู, เปลวไฟ, ขา), `"50% 50%"` (วงกระเพื่อม) — ไม่งั้นหู/หางหลุดออกจากตัว และวงกระเพื่อมไปโผล่มุมจอ
2. **ซับทับของสำคัญ**: ซับอยู่ที่ 1130–1300 เสมอ ของที่ต้องเห็น (ผิวน้ำ ตัวเลข ป้าย) วางเหนือ 1100
3. **ป้ายในภาพ (ข้อความในเอสวีจี)**: ต้องอยู่ระหว่าง 200–1100 และไม่ซ้อนกับซับ
4. **ใช้ `fromTo` เสมอ** ไม่ใช้ `from` (ภาพเพี้ยนตอนเลื่อนย้อน)
5. **ทุก id ต้องขึ้นต้นด้วยรหัสช็อต** (`s07-ears`) เพราะทุกช็อตรวมอยู่ในหน้าเดียวกัน
6. **ปุ่มเขียวในหน้าจอมือถือ** ใช้ `#1f7a3a` ขึ้นไป (เขียวอ่อนกว่านี้ไม่ผ่านความคมชัด)
