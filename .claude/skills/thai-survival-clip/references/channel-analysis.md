# วิเคราะห์ช่องละคร AI เอาชีวิตรอดที่ไวรัลใน TikTok — สูตรคลิป "ถ้า...คุณจะรอดไหม"

วิเคราะห์เมื่อ 29 ต.ค. 2026 จาก 13 คลิป (12 คลิปเนื้อหา + 1 คลิปโฆษณา ตัดออก)

## 1. ข้อมูลภาพรวม

| คลิป | วิว | ซีรีส์ / EP |
|---|---|---|
| ซอมบี้บุกโรงเรียน EP1 | 2.1M | โรงเรียน 1/3 |
| นอนเฝ้านา EP1 (ไม่ใช่ซอมบี้ — "วงเงียบ" ของกบ) | 1.2M | ทุ่งนา 1/2 |
| ซอมบี้บุกโรงเรียน EP2 | 909K | โรงเรียน 2/3 |
| ค้างภู EP1 | 734K | ภูเขา 1/2 |

| ซอมบี้บุกตอนอยู่บนดอย EP2 | 540K | ภูเขา 2/2 |
| ทุ่งเงียบ EP2 | 505K | ทุ่งนา 2/2 |

| ซอมบี้บุกกลางแพ EP4 (97s) | 284K | แพในเขื่อน |

| ซอมบี้บุก ตอนหมูกรอบมา (ตลก) | **7K** | เดี่ยว |

**ข้อสังเกตจากตัวเลข**
- ความยาวคงที่ **~69 วินาที** แทบทุกคลิป (เกิน 60s → TikTok นับเป็นคลิปยาว)
- **EP1 ของซีรีส์ใหม่ทำวิวสูงสุดเสมอ** แล้วลดหลั่นในตอนถัดไป (2.1M → 909K → 593K) → การเปิดซีรีส์/ฉากใหม่บ่อยๆ สำคัญกว่าลากยาว
- ฉาก **ใกล้ตัวคนไทยมากๆ** (โรงเรียน, เถียงนา, กางเต็นท์บนภู) ชนะฉากสากล (เครื่องบิน)
- คลิปที่ **เล่นตลก/ไม่มีเดิมพันจริง** (หมูกรอบ) ล่มที่ 7K → ความกลัว+ความรู้จริงคือหัวใจ ไม่ใช่มุก
- ภัยไม่จำเป็นต้องเป็นซอมบี้ — "สิ่งไม่รู้จักในทุ่งนา" ทำ 1.2M

## 2. โครงเรื่อง (Story Formula) — ใช้ซ้ำได้ทุกตอน

บทยาว ~250–330 คำไทย อ่านเร็ว ~4.5 คำ/วินาที แบ่ง 5 ท่อน:

### ① HOOK (0–8s) — ประโยคเปิดตายตัว
> **"ถ้า[ภัย] ตอนคุณ[สถานการณ์ใกล้ตัว] อย่า[สิ่งที่สัญชาตญาณบอกให้ทำ]"**
> + เหตุผลพร้อมตัวเลข 1 ตัว + **ประโยคเปิดลูป**

ตัวอย่างจริง:
- "ถ้าซอมบี้บุกโรงเรียนตอนคุณเรียนอยู่ชั้นสาม **อย่าวิ่งลงบันได**ตามเพื่อน คนแน่นเกิน 5 คนต่อตารางเมตร ล้มแล้วลุกไม่ขึ้น **คุณจะรอดถ้าไม่พลาดแค่เรื่องเดียว**"
- "ถ้ากบทั้งทุ่งเงียบพร้อมกันตอนคุณนอนเฝ้านา **อย่าเปิดไฟฉาย**…"
- "ถ้าสึนามิบุกตอนคุณอยู่บางแสน **อย่าวิ่งหนีน้ำ** ให้วิ่งหาบันได"

ประโยคเปิดลูปที่ใช้: "คุณจะรอดถ้าไม่พลาดแค่เรื่องเดียว" / "แต่ที่ตีนภูมีเรื่องเดียวที่คุณลืม" / "คำถามคือจะลงที่ไหน"

### ② SETUP ตัวละคร (8–15s)
- **"คุณ"** = ผู้ชม (บุรุษที่ 2 ตลอดเรื่อง)
- **สัตว์คู่หู 1 ตัว** — ทำหน้าที่ "เซ็นเซอร์เตือนภัย" (เจ้าด่าง, โอเลี้ยง, ขนุน, โกโก้, ลิงมะยม) ทุกครั้งที่มันหูตั้ง/ขู่ = มีอะไรมา
- **คนไทยธรรมดา 1 คน** — ลุงเชิด, ป้าร้านปู, ฟ้าหัวหน้าห้อง, พี่นุ่นลูกเรือ (มักเป็นตัวที่ทำพลาดหรือเป็นตัวปม)

### ③ BODY 3–4 บีท (15–55s)
แต่ละบีท = **การกระทำ + กฎเอาชีวิตรอด + ข้อเท็จจริงมีตัวเลข**
- บอกเวลาเป็นช่วงๆ: "สองทุ่ม", "บ่ายสาม", "ตีสามสิบ", "วันที่หก เก้าโมงเช้า"
- ข้อเท็จจริงจริง เช่น "จมูกหมามีตัวรับกลิ่น 300 ล้าน คนมี 6 ล้าน", "ทุก 1,000 เมตรเย็นลง 6.5 องศา", "ถังดับเพลิง 15 ปอนด์ฉีดได้ ~20 วินาที", "เกลือแร่: น้ำ 1 ลิตร น้ำตาล 6 ช้อนชา เกลือครึ่งช้อนชา"
- อ้างอิงเหตุการณ์/สถานที่ไทยจริง: สึนามิปี 47, สายด่วน 1669, เขาสามมุก, ถ้ำในอุทยาน
- **ฝังเบาะแส 1 อย่างแบบผ่านๆ** ที่จะกลับมาในตอนจบ (เสื้อแขนยาว, ล็อกรถด้วยรีโมท, ตั้งนาฬิกาปลุกตีสี่, ป้าปิดวาล์วแก๊ส)

### ④ TWIST (55–67s) — ประโยคตายตัว
> **"ทุกอย่างถูกหมด ยกเว้นเรื่องเดียว"** → เปิดเผยเบาะแสที่ฝังไว้ → จบห้วนๆ ทันที

- แบบ **ร้าย (cliffhanger)**: "ห้องร้อนขนาดนี้ มีคนเดียวที่ยังใส่เสื้อแขนยาว… เจ้าด่างไม่ได้ขู่ประตู มันขู่ฟ้ามาตั้งแต่แรก"
- แบบ **ดี (callback รางวัล)**: "ถังเดียวที่ไม่รั่ว คือถังที่ป้าปิดไว้" (ทำสิ่งที่ดูเสียเวลาตอนต้น = รอดตอนท้าย)
- twist มักใช้ **ข้อเท็จจริงจากบีทก่อนหน้า** มาหักมุม (เช่น สอนเรื่องเสียงตลอด → ตอนจบเสียงนาฬิกาปลุก/สัญญาณกันขโมยดัง)

### ⑤ OUTRO (67–69s)
โลโก้ช่อง 2 วินาที

### การต่อ EP
EP ถัดไปเปิดด้วย "ถ้า…" ที่หยิบจาก cliffhanger ตอนก่อนทันที
("ถ้าบันไดที่คุณดึงขึ้นถูกพาดลงไปเองตอนตีสี่ อย่าเอื้อมไปดึง…")
ซีรีส์ละ 2–4 ตอน แล้วเปิดฉากใหม่

## 3. Style Bible (ภาพ)

- **สไตล์**: 2D flat vector แบบ explainer, เงานุ่ม, มี film grain + vignette เข้ม ทำให้ดูหม่นๆ ลุ้นๆ
- **สี**: โทนกดลง (desaturated) — กลางคืนน้ำเงินม่วง, ในอาคารเบจ/ครีม, แดงใช้เป็นสีเน้นอันตราย
- **ตัวละคร**: หัวกลม ตัวผอมสูงแบบไม้ขีด หน้าเรียบง่าย ใส่ชุดไทยจริง (ชุดนักเรียน, ชุดครู, ม่อฮ่อม)
- **ฉาก**: ไทยแท้ (ธงชาติหน้าเสาธง, กระดานเขียน "ม.4/2 คาบ 3", เถียงนา, ร่มชายหาดบางแสน)
- **มุมกล้อง**: สลับ wide establishing / top-down (ฝูงคน) / close-up มาก (จมูกหมา, มือถือ) / POV มือผู้ชม
- **การเคลื่อนไหว**: น้อย — ภาพนิ่งที่ขยับเบาๆ ซูมช้า ตัวละครขยับเล็กน้อย (ลักษณะ image-to-video AI) ~10–11 ช็อต/คลิป ≈ 6 วินาที/ช็อต
- **UI overlay** (ตัวช่วยเล่าเรื่องสำคัญ):
  - การ์ดข้อมูล: "ความหนาแน่นบนบันได 5 คน/ตร.ม. ⚠ อันตราย"
  - นาฬิกา/นับถอยหลัง: "เช้านี้ 07:50", "น้ำถึงฝั่งใน 00:12"
  - แจ้งเตือนมือถือ / สถานะข้อความ "ส่งแล้ว ✓"
- **ซับ**: ภาษาไทยกลางจอ ตัวขาว/เหลืองมีเงาเรือง วลีสำคัญใส่กล่องแดง ทีละวลีสั้น 2–5 คำ; คลิปใหม่ๆ เพิ่มซับอังกฤษตัวเล็กใต้ไทย
- **ขนาด**: 9:16 (576×1024 ต้นฉบับ)

## 4. สิ่งที่ยังไม่ได้วิเคราะห์ / ต้องตรวจเพิ่ม
- **เสียง**: ยังไม่ได้ฟัง — ต้องเช็กว่าเสียงพากย์เป็น AI TTS หรือคนจริง, โทน, BGM, SFX
- เครื่องมือที่ช่องใช้ผลิต (ช่องไม่ได้บอกไว้)

## 5. ข้อควรระวังตอนทำของตัวเอง
- เอา **สูตร** ไปใช้ แต่ตัวละคร ชื่อ สัตว์คู่หู สไตล์ภาพ และโลโก้ ต้องออกแบบใหม่เป็นของเรา
- ข้อเท็จจริงทุกตัวเลขในบทต้อง **ตรวจสอบจริง** — เพราะเป็นจุดขาย และคลิปแนวเอาชีวิตรอดถ้าให้ข้อมูลผิดอาจเป็นอันตรายต่อคนดู

## 6. โครงสร้างซีรีส์ (ตรวจเพิ่ม 29 ต.ค. 2026 จาก 28 คลิปล่าสุด)

| ซีรีส์ | จำนวนตอน | วิวแต่ละตอน | ตอนสุดท้ายจบยังไง |
|---|---|---|---|
| ซอมบี้บุกโรงเรียน | 3 (ลงวันเดียวกันทั้ง 3 ตอน) | 2.1M → 910K → 594K | คลายปมตอน 1 (ฟ้าไม่ได้ถูกกัด แค่โดนกระจกบาด) แล้วหักมุมใหม่ว่า "ต้น" ต่างหากที่ซ่อนแผล — ค้างไว้ ไม่มีตอน 4 |
| ค้างภู / ซอมบี้บุกดอย | 3 (ภายใน 2 วัน) | 734K → 541K → 266K | ค้าง: ปั๊มน้ำมันใช้ไฟฟ้า แต่ไฟดับทั้งอำเภอ — ไม่มีตอนต่อ |
| นอนเฝ้านา / ทุ่งเงียบ | 5 | 1.2M → 507K → 221K → ~70K → 62K | ตอน 5 (117 วิ) รอดเพราะลุงเอกมารับ "แต่เขารู้อะไรที่คุณไม่รู้" — ยังค้าง |
| ซอมบี้บุกกลางแพ | 4 | 282K → 140K → 322K → 285K | ตอนเดียวที่ "จบจริง": ล่อฝูงออกกลางเขื่อน เครื่องดับแต่มันว่ายน้ำไม่เป็น |
| ซอมบี้บนเครื่องบิน | 1 | 494K | ค้างแล้วไม่ทำต่อ |
| บางแสนแตก, จุดพักรถตีสาม, ชีวิตในกรุง | ตอนเดียวจบ | 132K / 74K / 16K | จบด้วยการเรียกเบาะแสต้นเรื่องกลับมาแบบดี (ถังแก๊สที่ป้าปิด) |

ข้อสรุป:
- ทุกตอนจบค้างด้วย "ทุกอย่างถูกหมด ยกเว้นเรื่องเดียว" และตอนถัดไปเปิดด้วย "ถ้า…" ที่หยิบปมนั้นมาทันที
- ตอนถัดไปมักคลายปมตอนก่อนแบบพลิก (สิ่งที่คิดว่าอันตรายไม่อันตราย แต่อันตรายจริงอยู่ที่อื่น)
- ลงตอนต่อเร็วมาก (วันเดียวกัน–2 วัน) ตอนที่ตอนแรกยังร้อน
- ส่วนใหญ่ไม่มีตอนจบจริง — หยุดเมื่อวิวตก; ซีรีส์ปกติ 3 ตอน ซีรีส์ที่ดังลากถึง 4–5 ตอน และตอนหลังๆ ยาวขึ้น (97–117 วินาที)
- ซีรีส์ใหม่ช่วงหลัง (หมอกดอย, หมอกในร้านสะดวกซื้อ, Dark Room) ตอน 1 ได้แค่ 3K–30K → กระแสของช่องเริ่มลดลง
