# สกิล thai-survival-clip — วิธีใช้

สกิลสำหรับ Claude Code ที่ทำคลิปแอนิเมชันแนวตั้ง (ติ๊กต็อก / รีลส์ / ชอร์ตส์) แนว **"ถ้า…คุณจะรอดไหม"** เป็นซีรีส์ภาษาไทย
พิมพ์บอก Claude แค่ "ภัยอะไร ที่ไหน กับสัตว์อะไร" แล้ว Claude จะพาทำตั้งแต่วางเรื่องจนได้ไฟล์ MP4

## ได้อะไร
- คลิปแนวตั้ง 1080×1920 ยาว ~68 วินาที พร้อมลงติ๊กต็อก
- บทภาษาไทยตามสูตรไวรัล: เปิดด้วย "ถ้า… อย่า…", สอนความรู้จริงที่มีตัวเลข (ตรวจข้อเท็จจริงจากเว็บ), จบด้วยหักมุม "ทุกอย่างถูกหมด… ยกเว้นเรื่องเดียว"
- เสียงพากย์ไทยโทนต่ำ ลุ้น มีกระซิบ
- ภาพเวกเตอร์แบนวาดด้วยโค้ด ตัวละครหน้าตาเหมือนเดิมทุกตอน
- ซับไทยตรงเสียงทุกวลี การ์ดข้อมูล ดนตรี เสียงประกอบ
- ทำต่อเป็นตอนที่ 2, 3, … ได้ ตัวละครและฉากใช้ต่อกันได้

## ต้องมีอะไรบ้าง
| อย่าง | หมายเหตุ |
|---|---|
| **Claude Code** (แอปเดสก์ท็อป หรือในเทอร์มินัล) | ต้องเป็น Claude Code เพราะต้องรันโปรแกรมในเครื่อง |
| **เครื่องแมค** (แนะนำ แรม 8 GB ขึ้นไป) | ใช้ฟอนต์ไทยที่มากับเครื่อง; วินโดวส์/ลินุกซ์ใช้ได้แต่ต้องหาฟอนต์ไทยเอง |
| **ffmpeg, Node.js, Python 3, uv** | ถ้ายังไม่มี บอก Claude ว่า "ช่วยติดตั้งให้หน่อย" |
| **บัญชี ElevenLabs** (มีแพ็กฟรี) | สำหรับเสียงพากย์ — ส่วนเดียวที่ใช้บริการภายนอก |
| พื้นที่ว่าง ~4 GB | โมเดลสร้างดนตรีที่ดาวน์โหลดครั้งแรก |

## ติดตั้ง (ครั้งเดียว)
1. ดับเบิลคลิกไฟล์ `thai-survival-clip.skill` (หรือแตกไฟล์ zip ไปไว้ที่ `~/.claude/skills/thai-survival-clip/`)
2. ติดตั้งสกิลไฮเปอร์เฟรมส์ (ใช้ร่วมกัน) — พิมพ์ในเทอร์มินัล:
   ```bash
   npx hyperframes skills update
   ```
3. ตั้งค่าคีย์ ElevenLabs:
   - เข้า elevenlabs.io → **Developers → API Keys** → สร้างคีย์
   - เปิดสิทธิ์ **Text to Speech** และ **Voices: Read**
   - สร้างไฟล์ชื่อ `.env` ในโฟลเดอร์งานของคุณ ใส่บรรทัดเดียว: `ELEVENLABS_API_KEY=คีย์ของคุณ`
   - **อย่าส่งคีย์ให้ใครหรือวางลงในแชต** — แค่บอก Claude ว่าไฟล์ `.env` อยู่ที่ไหน
4. เปิดโฟลเดอร์งานใน Claude Code แล้วเริ่มได้เลย

## วิธีใช้
พิมพ์คุยกับ Claude ตามปกติ ตัวอย่าง:
- `อยากทำคลิปเอาชีวิตรอด ติดอยู่ในลิฟต์คอนโดตอนไฟดับ กับหมาชิวาวา`
- `ทำซีรีส์ใหม่ ถ้าไฟป่าลามถึงหมู่บ้านบนดอย มีแมวดำด้วย`
- `ทำตอนที่ 2 ของซีรีส์น้ำท่วมหมู่บ้านต่อ`
- `ยังคิดไม่ออก ช่วยเสนอไอเดียซีรีส์ 5 เรื่องหน่อย`

Claude จะทำตามลำดับนี้ และ **หยุดถามคุณ** ที่จุดสำคัญ:
1. วางซีรีส์และตัวละคร → ให้คุณเลือก/แก้
2. เขียนบท + ตรวจข้อเท็จจริง → **ให้คุณอนุมัติก่อนสร้างเสียง** (เพราะเสียงกินเครดิต)
3. สร้างเสียงพากย์ → ส่งให้ฟัง
4. วาดฉาก ทำซับ ดนตรี เสียงประกอบ → ตรวจภาพเอง แก้จุดเพี้ยน
5. เปิดหน้าพรีวิว (แก้ข้อความ/เลื่อนเวลาเองได้ในเบราว์เซอร์) → เรนเดอร์ → ส่งไฟล์ MP4

ทั้งตอนใช้เวลาราว 30–60 นาที (ตอนแรกนานสุด เพราะต้องดาวน์โหลดโมเดลดนตรี)

## สิ่งที่คุณต้องเช็กเอง
Claude ฟังเสียงไม่ได้ (วัดได้แค่ความดังและจังหวะ) ก่อนลงคลิปให้ฟังเช็ก:
- ดนตรีเพราะ/เข้ากับเรื่องไหม
- ซับตรงกับเสียงพูดไหม
- เสียงประกอบดังหรือเบาเกินไหม
แจ้ง Claude ได้เลย เช่น "ดนตรีช่วงหักมุมดังไป" หรือ "ซับวินาทีที่ 40 เร็วไป"

## ค่าใช้จ่าย
- **ElevenLabs แพ็กฟรี**: ราว 10,000 ตัวอักษร/เดือน ≈ 5–6 ตอน (รวมทำซ้ำ) ใช้ได้เฉพาะเสียงสำเร็จรูป (ค่าเริ่มต้นของสกิลคือเสียง "George" ซึ่งใช้ได้)
- **ถ้าช่องหารายได้** (Creator Rewards, รับงานโฆษณา) แพ็กฟรีไม่ครอบคลุมการใช้เชิงพาณิชย์ — ควรใช้แพ็ก Starter (ประมาณ 5 ดอลลาร์/เดือน) ขึ้นไป ซึ่งปลดล็อกเสียงไทยในคลังด้วย เช่น "Duang" ที่เป็นคนไทยเสียงทุ้ม (ตรวจราคาและเงื่อนไขล่าสุดที่เว็บ ElevenLabs)
- ส่วนอื่นฟรีทั้งหมด (ภาพ ดนตรี เสียงประกอบ ทำในเครื่อง)

## เคล็ดลับ
- **สถานที่ใกล้ตัวคนไทย** (โรงเรียน คอนโด ทุ่งนา รถไฟฟ้า) ได้ผลดีกว่าฉากต่างประเทศ
- **อย่าเล่นตลก** แนวนี้ต้องลุ้นและน่ากลัวจริง
- **ลงตอนต่อเร็ว** ภายใน 1–2 วัน ตอนแรกยังร้อนอยู่
- วางแผน 3 ตอน ให้ตอน 3 จบจริง ถ้าตอน 1 ดังค่อยขยาย
- ใช้แค่ "สูตร" ตัวละคร สัตว์ ฉาก และเรื่อง ต้องเป็นของคุณเอง อย่าลอกช่องอื่น
