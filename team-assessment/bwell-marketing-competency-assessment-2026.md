## 1. Rating Scale (1–5)

| Score | Level | นิยามทั่วไป |
|---|---|---|
| 1 | Beginner | มีความรู้พื้นฐานน้อยมาก ต้องสอนและกำกับทุกขั้นตอน |

## 3. Part A — Core Competencies (ทุกตำแหน่ง)

### A1. Brand & Product Knowledge

| # | Competency | L1 Beginner | L3 Proficient | L5 Expert | Self | Mgr | หลักฐาน (ถ้าให้ 4–5) |
|---|---|---|---|---|---|---|---|

| A1.2 | Brand CI (สี โลโก้ ฟอนต์) | ไม่รู้ค่า CI ใช้สี / ฟอนต์ผิดบ่อย | รู้ Primary Blue `#0d99db`, Navy `#005D9D`, Gradient 180°, ฟอนต์ DB Helvethaica X / Kanit / Poppins, logo clear space และใช้ได้ถูกต้อง | ตรวจงาน agency / KOL / retail POP แล้วจับจุดผิด CI ได้ทั้งหมด และเสนอการปรับ guideline ได้ | | | |
| A1.3 | Brand Voice & Tone | เขียนไม่ตรง tone ใช้สรรพนามผิด โอเวอร์เคลม | เขียนตาม tone ของแต่ละ channel ใช้ "คุณ" อิงข้อมูล ไม่เคลมเกินจริง | เขียน voice guideline หรือ template ให้ทีมใช้ได้ งานของตนเป็นตัวอย่างอ้างอิง | | | |
| A1.4 | Product Knowledge | รู้จักสินค้าเพียง 1–2 หมวด อธิบาย spec ไม่ได้ | อธิบาย key feature, spec สำคัญ, จุดต่าง และ use case ของสินค้าหลักทุกหมวดได้ถูกต้อง | ตอบคำถามเชิงเทคนิคได้ลึก (เช่น CADR, filter type, ความจุ, certification) แปลง spec เป็น benefit ได้ และเป็นที่ปรึกษาเรื่องสินค้าให้ทีม | | | |

## 6. วิธีคิดคะแนน

| ขั้นตอน | สูตร |
|---|---|
| 1. คะแนนรายข้อ (Final) | ใช้คะแนนหลัง Calibration ถ้าไม่ได้ Calibrate ใช้คะแนน Mgr |
